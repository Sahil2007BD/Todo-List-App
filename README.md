# 📝 To-Do List App

A simple and clean **To-Do List web application** built using **HTML, CSS, and JavaScript**.
This project allows users to add, manage, and delete tasks easily.

## 🚀 Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Simple and responsive design
* Clean and beginner-friendly code

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## 📷 Preview

🔗 Live Demo: https://sahil2007bd.github.io/Todo-List-App/


## 💡 Purpose

This project was created to practice **JavaScript DOM manipulation** and build a basic interactive web application.
